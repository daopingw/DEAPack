# Source-freeze protocols

This directory records evidence gates for methods whose economic question is
important to DEAPack. A gate can remain blocked or deferred, become
source-frozen and implementation-ready, or be retained as the provenance
record after a method is implemented.

A protocol is not by itself a method registration, implementation promise, or
public API. Its readiness table states the current disposition. This
separation prevents a plausible reconstruction from being mistaken for the
source method and lets unresolved literature stay explicitly deferred to a
later version.
