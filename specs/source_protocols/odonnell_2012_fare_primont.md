The current release will not implement or register the Färe--Primont
candidate. An author working paper and its artificial-data example have been
located, but the final journal article has not been obtained and checked
page-by-page against that manuscript. The reported numerical vector has also
not yet been independently reproduced.

The existence of reusable radial distance code does not close either gap.
Färe--Primont is a complete fixed-reference aggregate-quantity account, not a
renamed Malmquist or Hicks--Moorsteen calculation.

## 1. Defining source

Christopher J. O'Donnell (2012), “An aggregate quantity framework for
measuring and decomposing productivity change,” *Journal of Productivity
Analysis*.
[DOI](https://doi.org/10.1007/s11123-012-0275-1).

An earlier author working paper is useful discovery evidence. Until its
equation, table, and notation correspondence with the final publication is
audited, it is not treated as the frozen executable source.

## 2. Work postponed to the next version

The future source audit must:

1. obtain the complete final journal article through authorized access;
2. compare every relevant final equation with the author manuscript;
3. freeze the output and input aggregator definitions, common reference
   observation, technology, returns-to-scale assumptions, and all DEA tasks;
4. freeze the native TFP index and every advertised efficiency, scale, mix,
   and residual component identity;
5. independently reproduce the artificial-data example and its complete
   Färe--Primont output vector; and
6. document which results are produced by the source method itself and which
   are separate DPIN software conventions.

DPIN feature descriptions are not a transparent numerical oracle. A future
implementation must compare task-level distances and reconstructed
identities, not merely produce a plausible productivity ranking.

## 3. Non-equivalence boundary

The candidate must remain distinct from:

- Bjurek's implemented adjacent-period Hicks--Moorsteen index;
- the implemented adjacent-period, global, and biennial Malmquist operators;
- an arithmetic or geometric average of unit-level productivity indexes;
- a generic fixed-base index lacking the Färe--Primont aggregator; and
- profitability change, which additionally requires explicit price
  information and a separate accounting identity.

No public class, machine method record, catalog entry, or book recipe should
be added before the six-item gate is complete.
