# Data Envelopment Analysis

*Efficiency, Productivity, and Environmental Performance with Python*

```{epigraph}
A Unified Handbook of Theory, Methods, and Practice
```

**Daoping Wang**

This book serves readers encountering efficiency analysis for the first time and
researchers who need rigorous model choice, reproducible computation, and disciplined
reporting. The text explains why and when to use a method, while worked examples show
how its conclusions can be reproduced and examined with DEAPack.
