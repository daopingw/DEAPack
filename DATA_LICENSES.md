## Required mapping record

Add a dataset only after review records every field below and the authoritative
release sign-off approves it:

| Field | Required evidence |
|---|---|
| Dataset ID and content fingerprint | Exact public identifier and deterministic hash of the released values |
| Content location | Every source, wheel, sdist, Documentation, figure, and generated-output location |
| Origin classification | Project-created, source-derived, published reproduction, or third-party data |
| Factual creator/rightsholder | Confirmed person or entity; never inferred from Git history or a filename |
| Authority record | Origin declaration, employment clearance, upstream license, or permission reference |
| Content license | Exact SPDX identifier or precise source-specific terms |
| Attribution and citation | Required credit, source link, recommended scholarly citation, and modification statement |
| Required notice | Path and SHA-256 of the shipped license or permission notice |
| Release approval | Dated authoritative sign-off reference |

For a dataset confirmed to be wholly project-created and licensable by the
project, the adopted outgoing license is `CC-BY-4.0`; the official text is
[`LICENSES/CC-BY-4.0.txt`](LICENSES/CC-BY-4.0.txt). The active project mappings
above are exact-hash assignments, not a floating default. External datasets
follow their own reviewed terms and never inherit `CC-BY-4.0` automatically.
