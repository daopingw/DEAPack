# MPSS research status

Most productive scale size (MPSS) remains a non-public development prototype in
this evidence version. Its source-native equations, economic semantics, and
independent numerical validation have not yet been closed together, so the
method is deferred to the next version.

This page intentionally contains no API example, equation, score
interpretation, or target contract. The evidence needed to reopen the method
is tracked in the
[Banker MPSS source protocol](https://github.com/daopingw/DEAPack/blob/main/specs/source_protocols/banker_1984_mpss.md).
